# 출처 및 제출 범위

원본 저장소는 https://github.com/josephyumss/test_drive 이며 추출 기준 커밋은 `ba6cb97`입니다. 이 저장소는 대회 제출을 위해 두 회피 모드의 Jetson 실행 경로를 분리한 것입니다.

## 보존한 동작

다음 주행·통신 핵심은 원본과 동일합니다.

- `full_run.py`: fixed/dynamic 계획, 상태 전이와 주행 제어
- `reactive_avoidance.py`: 센서 융합, 곡선 경로, 위치 추정
- `full_run_legacy.py`, `full_run_uart.py`: 기존 STM32 상태 해석
- 측면센서 입력, 정지 요청, 기록·진단, 카메라 추론 및 UDP 브리지
- 실제 운용에 사용한 `config/full_run.json` 파라미터

## 분리를 위한 변경

- 패키지 초기화에서 옛 통합 제어기와 바이너리 프로토콜의 자동 import를 제거했습니다.
- `ascii_serial_bridge.py`에서 회피 로직이 사용하는 11필드 STATUS 자료형·파서만 추출했습니다. 파서의 검증 동작은 유지했습니다.
- 런처의 진단 소스 목록에서 포함하지 않는 STM32 펌웨어·바이너리 프로토콜을 제거했습니다. 런처는 실행에 사용한 소스를 계속 기록합니다.
- ROS 패키지는 실제 사용하는 UDP 브리지 실행점과 `ObstacleInfo` 메시지만 남겼습니다.
- 설치·환경 검사의 안내문과 테스트를 제출본 구성 및 현재 설정값에 맞췄습니다.
- Linux 검증에서 확인된 종료 확인 오류를 수정했습니다. 종료된 런처가 부모의 회수를 기다리는 좀비 상태인 경우에도 정상 종료로 판정합니다.
- Python 패키지 설정, LF 줄바꿈, 제외 규칙, README와 CI를 추가했습니다.

STM32 프로젝트, 지도·내비게이션, 모니터링 웹 UI, 과거 일회성 회피 실험, 보고서와 대용량 로그는 제출본에 포함하지 않습니다. 모델·LiDAR 드라이버·컨테이너 이미지 등 외부 의존성은 설치 스크립트가 준비합니다.
